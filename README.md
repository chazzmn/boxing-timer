# Boxing / HIIT Round Timer

A single-file interval timer for boxing and HIIT training. Editable rounds, work/rest intervals, prepare countdown, warning beeps, loud boxing-bell round signals, savable presets, screen wake-lock, and a fight-philosophy quote on every launch.

Live: https://boxing-timer-two.vercel.app

## Clock (temporary)

`clock.html` is a simple standalone countdown with a soft tick-tock while it runs and a ringing alarm bell that rings for 10 seconds. It's linked from the "Clock" button on the main page. To remove it, delete `clock.html`, the `navlink` line and its two CSS rules in `index.html`, and this section.
